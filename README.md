# VayuMitra AI — Urban Air Quality & Smog Assistant
Built for **Hack2Skill Virtual: PromptWars (Challenge 6)**.

## Overview
VayuMitra AI helps families and communities navigate severe winter smog using real-time Open-Meteo AQI telemetry and Google Gemini structured generation.

## Key Features
- **Live Hyper-Local AQI & Global Autocomplete:** Real-time PM2.5, PM10, and US AQI tracking via Open-Meteo APIs.
- **Low-Emission Daily Routines:** Time-blocked schedules aligned with winter temperature inversion windows.
- **Indoor Air Quality Hacks:** Practical, budget-friendly IAQ improvements with estimated particulate reduction.
- **Health & Training Yoga Sessions:** AQI-aware pranayama and indoor athletic conditioning with an interactive breathing pacer.
- **Sustainable Swaps & Impact Meter:** Quantified weekly CO2 and PM2.5 savings.
- **Multilingual Voice Read-Aloud:** Optional Web Speech briefing starting with *"Hello sir"*.
